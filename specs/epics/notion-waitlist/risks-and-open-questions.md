# notion-waitlist — risks and open questions

| ID | Risk | State | Notes |
|---|---|---|---|
| NW-A | `baseline-v1` is not yet proven live | OPEN | Proven offline in Baseline CI: the offline bootstrap with the blueprint's own hooks, the stage lane's own steps in a staged job tree, the site served by `wrangler dev` and smoke-tested with the component's own command — not connected, and connected to a local stand-in. A console bootstrap closes it |
| NW-B | A real signup against Notion and Resend | OPEN | Offline, the stand-in reads back exactly what the two clients send (the page create with the database id, `Name` and `Email`; the email's sender, recipient, subject and HTML), but neither service has answered the Worker, and the first `wrangler secret bulk` on a Worker that does not exist yet has not run live (clerk-auth-starter's CK-B is the same push). Closed by storing the four keys on a live site's stage and signing up once |
| NW-C | Workers Rate Limiting is per location and eventually consistent | ACCEPTED | Cloudflare documents it as permissive: a visitor hitting two locations, or a burst before the count settles, can get past two a minute. Upstash was exact and sliding. For a waitlist it is a brake on abuse; an exact quota would need a KV or D1 counter |
| NW-D | Next 16.3.8, not the template's 14.2.4 | ACCEPTED | OpenNext 1.20 refuses Next 15.5 at build, and every OpenNext starter here is proven on 16.3.8; the template uses nothing Next 14 has that 16 removed but `request.ip` (now `CF-Connecting-IP`) |
| NW-E | No licence file | ACCEPTED | GitHub records none and the repository has no LICENSE; the README's "License" section allows personal and commercial use and modification and asks commercial users to consider supporting the author. The registry lists the row unlisted until its owner decides; the README credits the template by name and link |
| NW-F | `@notionhq/client` 2 bundles node-fetch | WATCH | The client imports node-fetch at load; the routes hand it the Worker's fetch, so node-fetch is never called. The Notion API version stays the client's 2022-06-28, which the template was written against |
| NW-G | The email is in the template author's voice | ACCEPTED | Its words are the template's ("I'm Lakshay…"); the product's README tells the owner to rewrite them. What routed mail to the author (the sender, the reply-to, the mailto) is the owner's now |
